Ardent is the Rust rewrite of [Dent](https://www.npmjs.com/package/@nsis/dent), a JavaScript implementation that predates it. Both aim for full feature parity.

**The playground is powered by Dent, not Ardent**. It allows you to try formatting NSIS scripts in your browser without installing anything.
